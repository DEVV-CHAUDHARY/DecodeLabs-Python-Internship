# Project 4 - The General Knowledge Quiz

A Python command-line quiz developed as part of the DecodeLabs Python Programming Industrial Training.

## Objective
Create a game that asks 3 general-knowledge questions, awards +1 point for every correct answer, and prints the final score.

## Concepts Used
- input()
- Variables
- Strings
- strip() for accidental surrounding whitespace
- lower() for case-insensitive answer matching
- if-else conditional logic
- Functions
- Score/state management
- f-string output

## Run
python quiz.py

## Requirement Mapping
- 3 questions: implemented
- +1 for each correct answer: implemented
- Final score: displayed
- Case-insensitive matching: lower()
- Accidental spaces: strip()
- Control flow: if / elif / else
